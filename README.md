🎯 Project Overview
This project involved developing an interactive Power BI dashboard to analyze pizza sales data. The goal was to provide actionable insights into business performance, helping to identify top-selling products, order patterns, and revenue trends.

🛠 Tools Used
Power BI Desktop: Used for data modeling, visualization, and report development.

DAX (Data Analysis Expressions): Used to create custom measures for key performance indicators (KPIs) like Total Revenue, Total Orders, and Total Pizzas Sold.

Data Modeling: Established a Star Schema by creating relationships between sales, orders, and product lookup tables.

💡 Key Insights
Based on the analysis, here are the main takeaways:

Product Performance: The Classic Deluxe Pizza is the top-performing item, generating the highest revenue. 
It is followed closely by the Hawaiian Pizza and Pepperoni Pizza, indicating that customers favor traditional, established menu items.

Category Trends: The Classic category is the primary driver of revenue, significantly outperforming other pizza categories in the current dataset.

Operational Patterns: The dashboard highlights a clear correlation between order volume and revenue generation, allowing for optimized inventory management based on high-demand pizza types.

📊 Dashboard Features
Executive KPIs: Real-time visibility into Total Revenue, Total Orders, and Total Pizzas Sold at the top of the dashboard.

Interactive Filtering: Users can filter the entire report by pizza category to drill down into specific segments.

Trend Analysis: A line-and-column chart that highlights revenue and order trends over time.

Top Performers: A ranked bar chart highlighting the top 5 best-selling pizzas by revenue
